## 🔍 Abordagem em QA

| Tipo | Descrição |
|------|-----------|
| **Caixa Preta** | Validação de comportamento externo e regras de negócio sem conhecimento da implementação |
| **Caixa Cinza** | Testes com conhecimento parcial da estrutura interna para otimizar a cobertura |
| **Caixa Branca** | Validação de lógica interna e cobertura de código com acesso completo ao fonte |
| **Testes de API** | Validação de rotas REST, status codes, payloads e contratos de interface |
| **Automação** | Automação de fluxos críticos com Selenium para garantir regressão contínua |
